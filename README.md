# DataKit

Flat folder of standalone Python helpers for everyday data work: CSV, Excel, Parquet, SQLite,
DuckDB, dates, text, HTTP. Copy a module into a project or import the folder.

This file is the reference: what exists and how it works. `RUNBOOK.md` is the procedures,
`CLAUDE.md` the agent rules, `TASK.md` the open items.

## What it is

Nineteen modules at the repo root, each a thin wrapper over the standard library or one
third-party package, with no package structure and no dependencies between them beyond the two
SQL helpers sharing `sql_identifiers.py`. Each module stands alone so it can be copied into a
project as one file.

## Why it exists

The same small helpers (read a CSV as dicts, parse a date, find files, query DuckDB into rows)
were being rewritten in every project. Keeping one copy of each here, with docstrings, made
them something to copy from rather than rewrite.

## How it works

Import what you need with the folder on the path (`pyproject.toml` sets `pythonpath` for the
tests). Most functions have docstrings. Table and column names passed to `db_utils.py` and
`duckdb_utils.py` must be plain identifiers (`[A-Za-z_][A-Za-z0-9_]*`); anything else raises
`InvalidIdentifierError` instead of being spliced into SQL. Values are always bound as
parameters; file paths and delimiters go through `sql_identifiers.py` as quoted literals.

## Layout

| Module | What |
|---|---|
| `csv_utils.py` | CSV reading, writing and cleaning as lists of dicts |
| `excel_utils.py` | XLSX reading and writing with openpyxl |
| `parquet_utils.py` | Parquet read, write, schema, row groups, merge, partition, filter |
| `json_utils.py` | JSON and JSONL helpers, an encoder for datetimes, decimals, sets and paths |
| `db_utils.py` | SQLite helpers |
| `duckdb_utils.py` | DuckDB queries, imports and exports |
| `sql_identifiers.py` | validates and quotes table and column names for the two modules above |
| `dt_utils.py` | datetime parsing, ranges, business days |
| `text_utils.py` | string cleaning, slugs, extraction, case conversion |
| `validators.py` | emails, URLs, phones, postcodes, card numbers |
| `scraper.py` | requests plus BeautifulSoup page fetching and extraction, with rate limiting |
| `api_utils.py` | an API client with retry |
| `config_loader.py` | configs from JSON, YAML or environment variables |
| `log_setup.py` | logging configuration |
| `cache.py` | a file cache with TTL and a decorator |
| `file_utils.py` | find, copy, move, hash, size, read and write |
| `cli_helpers.py` | progress bars, colours, prompts, tables |
| `converters.py` | unit conversions and byte sizes |
| `zip_utils.py` | zip create, extract, list, read, add |
| `tests/` | pytest tests, one file per tested module; `TASK.md` says what is covered |
